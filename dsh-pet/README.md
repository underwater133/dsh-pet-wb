# dsh-pet-wb 🐾

一只住在桌面上的透明宠物，一百余个透明动画，可多开、能上桌面。

本仓库是 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的 fork，只做两件事：
跟随 **WorkBuddy 的会话状态**（`--host workbuddy` + WorkBuddy hooks）、以及 **Windows 上的一键启停与托盘退出**。

安装与完整文档：**<https://github.com/underwater133/dsh-pet-wb>**

上游项目、素材链与完整功能说明：**<https://github.com/PC2005-cloud/dsh-pet>**
